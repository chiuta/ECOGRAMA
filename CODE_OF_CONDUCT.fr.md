# Code de conduite

Soyez respectueux et constructif. Le harcèlement, la discrimination, les attaques personnelles, la divulgation de données personnelles et le spam ne sont pas acceptés. Les mainteneurs peuvent modifier, masquer ou supprimer des contributions et bloquer les participants qui ne respectent pas ces règles. Signalez les problèmes en privé à alexio@trom.tf. ECOGRAMA suit l’esprit trade-free : pas de suivi, pas de dark patterns, pas de coûts cachés.

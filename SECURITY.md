# Politica de securitate / Security policy

**RO.** Raportează vulnerabilitățile în privat (nu într-un issue public), la alexio@trom.tf, cu pași de reproducere, versiune și sistem. Parserele care citesc fișiere necunoscute sunt ținta principală: orice panică sau citire în afara limitelor este o vulnerabilitate.

**EN.** Please report vulnerabilities privately (not in a public issue) to alexio@trom.tf with reproduction steps, version and platform. Parsers that read untrusted files are the main target: any panic or out-of-bounds read counts as a vulnerability.

Versiuni suportate / Supported: ultima versiune minoră / latest minor release.

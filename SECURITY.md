# Security policy

**English** · [Română](SECURITY.ro.md) · [Français](SECURITY.fr.md) · [Italiano](SECURITY.it.md) · [Español](SECURITY.es.md) · [Português](SECURITY.pt.md) · [Deutsch](SECURITY.de.md) · [Magyar](SECURITY.hu.md)

Please report vulnerabilities privately (not in a public issue) to alexio@trom.tf with reproduction steps, version and platform. Parsers that read untrusted files are the main target: any panic or out-of-bounds read counts as a vulnerability.

Supported versions: the latest minor release.
